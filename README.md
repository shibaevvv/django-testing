# Django Testing - тестирование веб-приложений

Учебный проект по автоматизированному тестированию двух веб-приложений на Django с использованием unittest и pytest.

Цель проекта — проверка корректности работы веб-приложений, бизнес-логики, разграничения прав доступа и обработки пользовательских действий.

## Тестируемые приложения

### YaNote - unittest

Веб-приложение для создания и управления личными заметками.

Реализованы тесты:
- Доступности страниц и корректности HTTP-ответов.
- Авторизации и разграничения прав доступа.
- Создания, редактирования и удаления заметок.
- Валидации данных и уникальности идентификаторов заметок.
- Корректности содержимого страниц и передаваемых форм.

### YaNews - pytest

Новостной веб-сервис с возможностью комментирования публикаций.

Реализованы тесты:
- Доступности страниц для различных категорий пользователей.
- Создания, редактирования и удаления комментариев.
- Запрета изменения чужих комментариев.
- Валидации комментариев и фильтрации запрещённых слов.
- Сортировки новостей и комментариев.
- Ограничения количества публикаций на главной странице.

## Инструменты

- Python
- Django
- unittest
- pytest
- pytest-django
- Django Test Client

## Организация тестирования

Тесты сгруппированы по трём направлениям:

- `test_routes.py` — маршруты и права доступа.
- `test_content.py` — содержимое страниц и отображение данных.
- `test_logic.py` — бизнес-логика и пользовательские сценарии.

Для подготовки тестовых данных используются фикстуры pytest и механизмы Django TestCase.

## Запуск тестов

Установить зависимости:

```bash
pip install -r requirements.txt
```

Запустить проверки из корневой директории проекта:

```bash
bash run_tests.sh
```
